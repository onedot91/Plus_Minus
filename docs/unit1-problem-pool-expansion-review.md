# 1단원 문제풀 확장 검토안

목표: 기존 1단원 9단계 구조는 유지하고, 한 판에 노출되는 문제 수를 늘리기보다 단계별 후보 문제풀을 넓힌다. 난이도는 현재 기본 단원평가 수준으로 맞추고, 해설은 추가하지 않는다.

## 1단계: 직선, 선분, 반직선

기존 형식: 선 그리기, 선 이름 쓰기

추가 후보:
- 두 점 ㄷ, ㄹ을 곧게 이어 선분을 만들어 보세요.
- 점 ㅁ과 점 ㅂ을 이어 선분을 완성해 보세요.
- 두 점 ㅅ, ㅇ을 지나 양쪽으로 끝없이 이어지는 직선을 만들어 보세요.
- 점 ㄷ과 점 ㅁ을 지나 계속 이어지는 직선을 그려 보세요.
- 점 ㄹ에서 시작해 점 ㅂ 쪽으로 이어지는 반직선을 만들어 보세요.
- 시작점 ㅅ에서 한쪽으로 끝없이 이어지는 반직선을 그려 보세요.
- 제시된 선의 이름을 써 보세요. 정답 후보: 선분ㄷㄹ, 선분ㄹㄷ
- 제시된 선의 이름을 써 보세요. 정답 후보: 직선ㅁㅂ, 직선ㅂㅁ
- 제시된 선의 이름을 써 보세요. 정답 후보: 반직선ㅅㅇ

구현 메모:
- `SHAPE_READ_LINE_LABEL_SETS`에 이미 여러 점 이름 조합이 있어, 1단계 엔트리에서 `figureVariant` 사용 폭을 넓히는 방식이 적합하다.
- 반직선은 방향이 있으므로 역순 답을 허용하지 않는 현재 구조를 유지한다.

## 2단계: 각

기존 형식: 각 그리기, 각 이름 쓰기

추가 후보:
- 점 ㄷ을 꼭짓점으로 하는 각을 만들어 보세요.
- 점 ㄹ에서 시작하는 두 반직선으로 각을 완성해 보세요.
- 두 반직선이 만나는 점을 꼭짓점으로 하여 각을 그려 보세요.
- 각을 보고 이름을 써 보세요. 정답 후보: 각ㄷㄹㅁ, 각ㅁㄹㄷ
- 제시된 각의 이름을 써 보세요. 정답 후보: 각ㅂㅅㅇ, 각ㅇㅅㅂ
- 그림 속 각을 읽고 이름을 써 보세요. 정답 후보: 각ㄱㅁㅂ, 각ㅂㅁㄱ
- 각의 꼭짓점 이름을 써 보세요. 정답 후보: ㄴ, ㄷ, ㄹ 등

구현 메모:
- 각 이름 쓰기는 `SHAPE_READ_ANGLE_LABEL_SETS` 확장이 가장 작고 안전하다.
- “꼭짓점 이름 쓰기”는 현재 `identifyVariant`에 별도 타입이 없어 새 변형이 필요하다. 1차 반영에서는 각 이름 쓰기 변형 확대를 우선 권장한다.

## 3단계: 직각

기존 형식: 접기 애니메이션 이름 쓰기, 정의 빈칸, 직각 그리기

추가 후보:
- 종이를 반듯하게 두 번 접었을 때 생기는 각을 무엇이라고 하나요?
- 빈칸에 알맞은 말을 써 보세요: 반듯하게 두 번 접었을 때 생기는 각을 [직각]이라고 합니다.
- 점 ㄷ에서 두 반직선을 그어 직각을 만들어 보세요.
- 꼭짓점 ㄹ을 기준으로 직각을 완성해 보세요.
- 주어진 반직선과 직각이 되도록 반직선을 하나 더 그어 보세요.
- 반직선 하나를 더 그어 직각을 만들어 보세요.

구현 메모:
- 현재 정의 빈칸 정답은 `반듯`, `두 번` 중심이다. `직각` 자체를 빈칸으로 묻는 변형을 추가하려면 정의 렌더링과 정답 토큰을 조금 확장해야 한다.
- 그리기 변형은 `figureVariant` 범위 확대가 적합하다.

## 4단계: 직각 찾기

기존 형식: 도형 속 직각 수, 여러 도형 직각 수, 직각 이름 쓰기, 시계 직각

추가 후보:
- 도형 속 직각이 모두 몇 개인지 써 보세요. 정답 후보: 2개, 3개, 4개
- 왼쪽 도형부터 직각이 몇 개인지 차례대로 써 보세요. 정답 후보: 4,0,2
- 세 도형의 직각 수를 차례대로 써 보세요. 정답 후보: 1,3,2
- 그림에서 직각인 각의 이름을 모두 써 보세요. 정답 후보: 각ㄱㄴㄷ, 각ㄷㄴㄱ 등
- 직각이 되는 시각을 모두 써 보세요. 정답 후보: 3시, 9시
- 시계에서 작은 쪽의 각이 직각인 시각을 찾아 써 보세요. 정답 후보: 3시, 9시

구현 메모:
- `RIGHT_ANGLE_MARK_ANSWER_TOKENS`, `RIGHT_ANGLE_COUNT_ANSWERS`, `RIGHT_ANGLE_NAME_PROBLEM_VARIANTS`, `CLOCK_RIGHT_ANGLE_OPTION_VARIANTS`를 확장하면 된다.
- 시계 문제는 현재 3시/9시만 정답 처리한다. 12시, 6시 등은 직각이 아니므로 보기 조합만 다양화하면 충분하다.

## 5단계: 직각삼각형

기존 형식: 분류, 정의 빈칸, 점 찍어 완성, 두 개 그리기

추가 후보:
- 직각이 있는 삼각형과 없는 삼각형으로 나누어 보세요.
- 삼각형 카드를 알맞은 칸에 넣어 보세요.
- 한 각이 직각인 삼각형을 무엇이라고 하나요?
- 직각이 한 개 있는 삼각형을 [직각삼각형]이라고 합니다.
- 나머지 한 점을 찍어 직각삼각형을 완성해 보세요.
- 주어진 선분에 점 하나를 더 찍어 직각삼각형을 만들어 보세요.
- 모양이 다른 직각삼각형 2개를 그려 보세요.

구현 메모:
- `RIGHT_TRIANGLE_CLASSIFY_VARIANTS`를 늘리면 단원평가의 “직각삼각형 고르기” 유형을 자연스럽게 흡수할 수 있다.
- 현재 정답 입력 방식은 분류형 자동 채점과 빈칸 토큰으로 충분하다.

## 6단계: 직사각형

기존 형식: 사각형 분류, 정의 빈칸, 점 찍어 완성, 두 개 그리기

추가 후보:
- 직사각형인 도형과 아닌 도형을 나누어 보세요.
- 직각의 수에 따라 사각형 카드를 분류해 보세요.
- 네 각이 모두 직각인 사각형을 무엇이라고 하나요?
- 사각형에서 네 각이 모두 직각이면 그 사각형은 [직사각형]입니다.
- 세 점을 보고 알맞은 곳에 한 점을 찍어 직사각형을 만들어 보세요.
- 선분을 이어 직사각형을 완성해 보세요.
- 모양이나 크기가 다른 직사각형 2개를 그려 보세요.

구현 메모:
- `RECTANGLE_CLASSIFY_VARIANTS`는 단원평가의 직사각형 포함 물건/도형 판단을 앱 형식에 맞게 바꾼 핵심 확장 지점이다.
- 기울어진 사각형은 기본 난이도에서는 오답 도형으로 두는 편이 명확하다.

## 7단계: 정사각형

기존 형식: 도형 분류, 정의 빈칸, 점 찍어 완성, 두 개 그리기

추가 후보:
- 정사각형인 도형과 아닌 도형을 나누어 보세요.
- 네 각이 모두 직각이고 네 변의 길이가 모두 같은 사각형을 무엇이라고 하나요?
- 정사각형의 뜻을 생각하며 빈칸을 채워 보세요.
- 세 점을 보고 알맞은 곳에 한 점을 찍어 정사각형을 만들어 보세요.
- 선분을 이어 정사각형을 완성해 보세요.
- 크기가 다른 정사각형 2개를 그려 보세요.
- 직사각형과 정사각형을 구별해 보세요.

구현 메모:
- `SQUARE_CLASSIFY_VARIANTS` 확장이 가장 효과적이다.
- 정사각형은 직사각형이기도 하지만, 이 단계에서는 “정사각형 찾기” 기준으로만 채점하는 현재 구조를 유지한다.

## 8단계: 평면도형

기존 형식: 직각삼각형, 직사각형, 정사각형 만들기 종합

추가 후보:
- 선분을 이어 직각삼각형을 완성해 보세요.
- 선분을 이어 직사각형을 완성해 보세요.
- 선분을 이어 정사각형을 완성해 보세요.
- 모양 또는 크기가 다른 직각삼각형 3개를 그려 보세요.
- 모양 또는 크기가 다른 직사각형 3개를 그려 보세요.
- 크기가 다른 정사각형 3개를 그려 보세요.
- 도구를 골라 알맞은 평면도형을 만들어 보세요.

구현 메모:
- 현재 8단계는 이미 후보 풀 9개 중 일부를 뽑는 구조다. 각 도형의 `figureVariant` 범위를 늘리고, `entriesPool` 문장 변형을 추가하는 것이 적합하다.
- 난이도 높은 복합 분류는 추후 고난도 문항으로 분리하는 편이 좋다.

## 9단계: 평면도형 심화

기존 형식: 평면도형 산성비

추가 후보:
- 1웨이브: 선분, 직선, 반직선, 각 중심
- 2웨이브: 직각, 직각삼각형, 직사각형, 정사각형 중심
- 3웨이브 이후: 전체 도형 혼합
- 같은 웨이브 안에서 필수 도형 조합을 더 다양화

구현 메모:
- 현재 9단계는 웨이브별 속도와 목표 개수가 이미 올라가는 구조다. 기본 문제풀 확장 작업에서는 도형 조합만 약간 넓히고, 목표 개수나 속도는 유지하는 편이 좋다.

## 1차 반영 권장 범위

1차로 반영하기 좋은 항목:
- 1단계: 선 이름 읽기 점 이름 조합 확대
- 2단계: 각 이름 읽기 점 이름 조합 확대
- 3단계: 직각 그리기 `figureVariant` 확대, 정의 문장 1개 추가
- 4단계: 직각 수/시계/각 이름 변형 확대
- 5단계: 직각삼각형 분류 카드 변형 확대
- 6단계: 직사각형 분류 카드 변형 확대
- 7단계: 정사각형 분류 카드 변형 확대
- 8단계: 기존 종합 문제 문장 변형 확대

이번에 보류하는 항목:
- 객관식 보기형 UI 신규 추가
- 생활 물건 이미지형 문제 신규 추가
- 고난도 또는 함정성 문항
- 9단계 속도/목표 개수 변경
